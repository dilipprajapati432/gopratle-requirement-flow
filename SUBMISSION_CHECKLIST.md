# Submission Checklist

Before submitting to GoPratle:

- [ ] Run backend locally and connect MongoDB
- [ ] Run frontend locally
- [ ] Test Planner flow
- [ ] Test Performer flow
- [ ] Test Crew flow
- [ ] Verify MongoDB documents
- [ ] Deploy backend
- [ ] Deploy frontend
- [ ] Set production environment variables
- [ ] Push frontend and backend to GitHub
- [ ] Record a 5-7 minute walkthrough
- [ ] Include live frontend URL and GitHub URLs in the final submission
